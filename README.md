# FlavorLab 2040

An interactive speculative design project exploring a future where taste
can be customized and programmed.

## Live Project

### [Explore FlavorLab 2040 →](https://post-crave-68450666.figma.site)

## Overview

FlavorLab allows users to design a personalized eating experience by
adjusting sensory dimensions such as sweetness, acidity, aroma, texture,
and temperature. The interface visualizes the resulting flavor profile
and generates a dish with ingredient and nutritional information.

## Key Features

- Interactive sensory controls
- Real-time flavor visualization
- Personalized dish generation
- Ingredient and nutritional breakdowns
- Responsive interactive experience
